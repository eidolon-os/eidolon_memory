## 规则

1. 仅当对话包含可长期追踪的关系、事实或明显情绪峰值时才写入；纯寒暄可跳过。
2. 创建房间前先调用「检查/列举已有房间」类工具，避免重复实体（如「我的狗」与「小狗_小白」）。
3. 若用户要求不再提及某人/某话题，应调用封存/状态类工具而非盲目追加。
