# 个人记忆：用户列表与人工验收

更新：2026-10-28。

## 当前行为

新建 Person 默认开启独立个人记忆，Person 和 Realm 在同一事务创建。重复创建请求不恢复已暂停记忆；停用人物后重新启用人物，也不自动恢复记忆。既有用户保留当前状态，不批量覆盖手动暂停。

Mobile 用户管理列表直接展示：人物启停状态、声纹未录入/已录入数量、个人记忆状态及开关。声纹管理返回后刷新；开关直接调用既有管理 API，暂停/恢复携带当前 person_revision。查询失败明确显示状态暂不可用且禁用开关，写入失败后重新读取权威状态，不显示虚假成功。

## 验收步骤

1. 在列表确认目标人物已启用、声纹已录入、个人记忆已开启。
2. 进入房间，自然说一句完整偏好，例如“我平时喜欢喝无糖乌龙茶，请记住我的这个偏好”。确认当前声音识别为目标人物，且本轮记忆状态有效。只说姓名不会获得身份授权。
3. 在服务端确认该轮绑定目标 Person/Realm，记忆观察被接纳并完成异步处理。模型口头说“记住了”不作为持久化证据。
4. 退出房间再进入，用完整问句问“我平时喜欢喝什么茶，你还记得吗？”本句同样需要成功识别。正确回答且对应Realm有召回记录，才证明跨会话长期记忆链路；同一房间内追问不能单独证明。
5. 可选：暂停该人物记忆，进入新房间追问；正常对话，但应无个人长期记忆读写。恢复后使用原Realm。也可让另一位已录入且有独立记忆的用户在新房间追问，确认不读取前一人的Realm。

不要用正在讨论的公开内容证明私有记忆泄露：同一房间已说出的内容本就属于现场对话。隔离测试应使用独立房间，并核对当前轮次的授权归属。
