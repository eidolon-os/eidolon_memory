# 统一 claim 写入与完整质量实验 — 2026-10-08

## 本轮实际改动

LLM 输出从互不关联的 fragments/triples 改为 claims：一个命题包含正文、原文证据，可选 fact。解析器转成已有 MemoryIntent 与 canonical ledger 写入；结构化 claim 的正文进入该事实的同一 drawer，纯文字事件沿用现有 fragment assertion。没有第二套事实源、索引旁路或查询词典。

旧持久化决定的默认值和 intent ID 不变，不重抽历史数据。纠正、硬遗忘、重投经过已有端口；模型不能自行声明内部 unified_claims 标记。KG 关闭时保留纯文字 assertion；KG 开启但运行时端口缺失时重试，避免静默丢失。受限设备/会话事实不能转成无该限制的图谱行，敏感 claim 不能借非敏感谓词扩大 KG 可见范围。

## 修复确认及未完成项

c-001：姓名“张丽”、中文“失眠”、一周时长同在一个结构化事实的正文。c-007：年龄“两岁”已作为文字 assertion 保存，但“我家狗多大”仍未取回它——是当前候选/排序问题，不能再说年龄没存。c-023：聚会与“张丽炖了红烧肉”各有自己的写入单元，后者不再因为同轮有三元组而被整体跳过。c-025：日本旅行愿望保存在文字 assertion，无须强造 KG 事实。

23 个缺失证据组中，15 个在可见投影已有匹配，8 个无匹配。后者还混有旧标签（wife/person 与 partner/colleague 前缀不符）、图谱通道要求与纯文字计划冲突、敏感 KG 不可见等问题，不能一律当成漏抽。

仍未解决：

1. **证据相关性和拒答。** nearest-neighbor 候选与图扩展会返回无关事实。冻结 top-k 中，负例最大 similarity 为 0.631，已匹配正例的最低最佳 similarity 为 0.394；单一阈值不能同时剔除这些负例并保留所有这些正例。audit_relevance.py 只作分数重叠检查，未模拟新候选或过滤 KG，不能拿来直接调生产阈值。
2. **上下文/时间。** c-038 对“退烧了”产生 self/has_state/发烧 的失效指令，与前轮 child/has_symptom/发烧 不符，实际未匹配。逐轮抽取没有前轮对话作为指代依据，不能靠猜测补齐。time 标签仍无固定日期真值，pronoun 的子串得分不证明解引用正确。
3. **语义原子性和跨轮补充。** claims 契约改善写入形状，但 JSON 校验不证明命题独立；例如 c-021 同一正文仍包含“喝茶/不喝咖啡”。同一结构化事实的新证据也不会自动重写已经完成的正文投影。后续不能凭本轮通过宣称任意子命题都可独立纠正。
4. **可读时效。** 成功处理尝试 total 中位数 7863.5ms、最大 22640ms；这些不含排队和失败尝试，不是发布到可读的延迟。ack、当前会话 history、语义投影三段验收仍需单独完成。
5. T1 上游候选仅独立实验，规模门禁未重新通过；公开服务评测、真实数据分布/目标设备也未完成。

因此本轮完成的是统一事实写入和失败定位，**不是 Memory 整体验收**。下一步优先分清相关性过滤、图扩展噪声和上下文缺失，先使用现有评测入口做单因素对照，不能直接增加查询改写或正则路由。

## 失败过程与证据边界

首个试跑遗漏 privacy_actions.reason 的必填说明，隐私轮持续失败，因此中止；第二轮发现逐轮用户提示仍要求旧 fragments，与系统 claims 冲突，也中止。两轮日志和 manifest 保留为 aborted-run1/2 与 manifest-run1/2，均不能作为完整质量结果。修复两处契约后才得到本轮完整结果。

probe-results.json 是最初三条语料各两轮的新旧提示词探索，含上述旧逐轮提示；retry-cases.json 是第二轮之前的 5 条检查，均不是最终全量验收。probe.py 用固定的初版系统提示词和当前解析器供复查，不能视为初次运行的逐字重放。

manifest.json 记录完整模型实验实际加载的代码/语料 SHA-256，prompt-run3.md 和 measured-llm.py.txt 保存测量版本。测后仅补 KG 关闭时的文字兼容分支、测试和文档，并移除提示词末尾空行；final-source-sha256.json 分开记录最终文件，不覆写实测哈希。该兼容分支不影响此次 KG 开启的实验。

完整默认回归 **1279 通过、4 跳过、11 排除**，另外 contracts/tests **73 通过**；随后 KG 关闭兼容与端口缺失测试补齐后，最终相关测试 **40 通过**。日志分别为 full-regression.txt、final-targeted-tests.txt。集成测试覆盖同一 claim 的写入、重投、精确纠正和硬删除后不复活，以及历史 intent identity 保持不变。

原始响应、抽取决定、投影快照、分组失败、账本计数/时序和前两轮失败日志均归档。本报告中“保留决定”不包含隐私 tombstone 对应的已删除内容；模型探针只使用明确授权的合成测试语料。凭据不入库。
